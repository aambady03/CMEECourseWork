## Week 4: Data Wrangling, Visualization, and Statistical Modeling

### Scripts Overview

#### 1\. Data Wrangling and Reformatting

**1\_DataWrangling.R** - Pound Hill Dataset Transformation

  - **Function:** Reads raw ecological data (`PoundHillData.csv`) and its corresponding metadata (`PoundHillMetaData.csv`).
  - **Wrangling Steps:**
    1.  Loads raw data as a matrix, then performs a **transpose** (`t()`) to move species names to columns.
    2.  Replaces species absences (empty strings) with `0`.
    3.  Converts the raw matrix into a data frame (`TempData`).
    4.  Utilizes the `reshape2::melt()` function to transform the data from **wide format** (species in columns) to **long format** (one row per observation, with a `Species` column and `Count` column).
  - **Data Tidying:** Converts key columns (`Cultivation`, `Block`, `Plot`, `Quadrat`, `Species`) to factors or integers for proper statistical analysis.
  - **Tidyverse Integration:** Demonstrates quick inspection using `dplyr::glimpse()` and simple filtering.

#### 2\. Advanced Visualization and Simulation

**2\_Girko.R** - Girko's Circular Law Simulation

  - **Function:** Simulates the spectral distribution of eigenvalues from large random matrices, illustrating **Girko's Circular Law**.
  - **Steps:**
    1.  Defines a function `build_ellipse` to create the theoretical circular boundary.
    2.  Generates a large $N \times N$ random matrix (`M`) using standard normal distribution values.
    3.  Calculates the complex **eigenvalues** of the matrix.
  - **Visualization:** Uses the `ggplot2` package to:
      * Plot the real vs. imaginary components of the eigenvalues as a scatter plot.
      * Overlay the theoretically predicted circular boundary (radius $\sqrt{N}$), confirming the law.
  - **Output:** Saves the resulting visualization to `results/Girko.pdf`.

#### 3\. Tidyverse-Based Statistical Modeling

**3\_PP\_Regress.R** - Predator-Prey Mass Regression Analysis

  - **Function:** Conducts a log-log linear regression analysis on predator-prey mass ratios, a common model in ecology.
  - **Data Cleaning:** Normalizes `Prey.mass` units (converting `mg` to `g`).
  - **Statistical Modeling (Tidyverse):**
      * Uses **`dplyr::group_by()`** and **`dplyr::reframe()`** to perform the regression (`lm(log10(Prey.mass) ~ log10(Predator.mass))`) **separately** for each unique combination of `Type.of.feeding.interaction` and `Predator.lifestage`.
      * Extracts key model statistics (slope, intercept, $R^2$, F-statistic, p-value) for each group, handling groups with insufficient data gracefully.
  - **Visualization:** Creates a complex `ggplot2` plot:
      * Uses **log-log scales** on both axes.
      * Colors points and regression lines by `Predator.lifestage`.
      * Uses **`facet_wrap()`** to create separate panels for each `Type.of.feeding.interaction`.
  - **Output:** Saves the regression results table to `results/PP_Regress_Results.csv` and the plot to `results/PP_Regress_Plot.pdf`.

## Getting Started

### Prerequisites

  * **R Packages:** These scripts require the following non-base packages to be installed:
      * `reshape2` (for data wrangling)
      * `ggplot2` (for visualization in 2\_Girko.R)
      * `tidyverse` (for visualization and modeling in 3\_PP\_Regress.R)
  * **Data Structure:** The required data files must be placed in the `../data/` directory relative to the script location.

### Installation

1.  Clone or download the repository content.
2.  Navigate to the `week4/code` directory.
3.  Install the required packages in your R console:
    ```r
    install.packages(c("reshape2", "tidyverse"))
    ```

### Usage

Run each script sequentially in your R console or RStudio:

```r
# 1. Data Cleaning and Reformatting
source("1_DataWrangling.R")

# 2. Girko's Circular Law Simulation and Plotting
source("2_Girko.R")

# 3. Predator-Prey Regression and Tidyverse Modeling
source("3_PP_Regress.R")
```

**Note**: Scripts 2 and 3 will automatically create the `results` directory and save PDF plots and CSV tables there.

### Help

  * **Wrangling Errors:** If `1_DataWrangling.R` fails, check that the `reshape2` package is installed and loaded (`library(reshape2)`).
  * **Tidyverse Errors:** If `3_PP_Regress.R` fails, ensure the `tidyverse` package is installed and loaded. Errors are likely due to groups having fewer than 3 data points, but the script contains a fix to handle this gracefully by returning `NA`.

## Key Learning Outcomes

  * **Data Wrangling**: Transforming data from wide to long format using `melt()` (essential for statistical modeling).
  * **Scientific Visualization**: Generating complex, publication-quality graphics using `ggplot2` (e.g., log-log plots, faceting).
  * **Statistical Modeling**: Performing grouped linear regression analysis efficiently using the Tidyverse (`group_by`, `reframe`).
  * **Mathematical Simulation**: Implementing mathematical theories (Girko's Law) and visualizing the results.
