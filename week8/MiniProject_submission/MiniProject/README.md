# MiniProject — Bacterial Growth Curve Modelling

**Author:** Anaga Ambady  
**Institution:** Department of Life Sciences, Imperial College London, Silwood Park Campus

---

## Overview

This project fits and compares three mathematical models — **Logistic**, **Gompertz**, and a **Quadratic polynomial** baseline — to 278 bacterial population growth curves spanning multiple species and temperatures (0–37 °C). Model selection uses AICc and Akaike weights. Model-averaged maximum growth rates (r_max) are then analysed as a function of temperature to characterise a thermal performance curve (TPC).

## R Package Dependencies

| Package      | Version  | Purpose                                                      |
|--------------|----------|--------------------------------------------------------------|
| `minpack.lm` | ≥ 1.2-4  | `nlsLM()` — Levenberg–Marquardt NLLS fitting (more robust than base `nls()`) |
| `MuMIn`      | ≥ 1.47   | `AICc()` computation for model selection                     |
| `dplyr`      | ≥ 1.1    | Data wrangling (part of tidyverse)                           |
| `tidyr`      | ≥ 1.3    | Pivoting / reshaping data (part of tidyverse)                |
| `readr`      | ≥ 2.1    | Fast CSV reading (part of tidyverse)                         |
| `ggplot2`    | ≥ 3.4    | All figures                                                  |
| `ggtext`     | ≥ 0.1.2  | Rich text labels in ggplot (species names in TPC figure)     |

Install all at once in R:
```r
install.packages(c("minpack.lm", "MuMIn", "tidyverse", "ggtext"))
```

LaTeX must be installed (e.g. TeX Live or MiKTeX) with `pdflatex` and `bibtex` on your PATH.

---

## How to Run

From the `MiniProject/` directory:

```bash
bash run_MiniProject.sh
```

This runs all five R scripts in sequence, then compiles the LaTeX report. The final PDF is produced at `report/report.pdf`.

**Note:** The raw data file `data/logistic_growth_data.csv` must be present before running.
