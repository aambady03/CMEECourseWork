## Week 3: R Programming Fundamentals and Statistics

### Scripts Overview

#### 1\. Statistical Analysis and Permutation Testing

**1\_temp\_correlation.R** - Key West Temperature Correlation

  - **Function:** Loads the `KeyWestAnnualMeanTemperature.RData` dataset.
  - **Analysis:** Calculates the **Pearson correlation coefficient** ($r$) between Year and Temperature.
  - **Hypothesis Testing:** Performs a **Monte Carlo permutation test** (10,000 shuffles) to derive a statistically rigorous p-value for the observed correlation.
  - **Output:** Displays the observed correlation and the Monte Carlo p-value; generates scatter and histogram plots.

#### 2\. Reusable Utility Functions

**2\_utility\_functions.R** - Basic Mathematical Checks

  - **`is.even(n)`:** Checks if an integer is even.
  - **`is.power2(n)`:** Checks if a number is a power of 2 using the $\log_2$ function.
  - **`is.prime(n)`:** Determines if a number is prime, composite, a unit, or zero.
  - **Purpose:** Demonstrates creating modular, reusable code units in R.

#### 3\. Data Manipulation and File I/O

**3\_tree\_heights.R** - Trigonometry and File I/O

  - **Function:** Defines `calculate_height` using $\text{height} = \text{distance} \times \tan(\text{radians})$.
  - **Data Processing:** Reads `trees.csv`, applies the height function **vectorized** to the data, and writes the result to `../results/TreesHts.cvs`.

**apply\_examples.R** (Code segment within module 3) - Matrix Operations

  - **Function:** Illustrates the use of the **`apply()`** function for calculations across matrix rows (Margin=1) and columns (Margin=2), calculating means and variances.
  - **Advanced Use:** Shows applying a custom, conditional function to matrix rows.

#### 4\. Performance Benchmarking

**4\_performance\_test.R** - Loops vs. Vectorization

  - **Experiment:** Repeatedly calculates the mean of a random sample (`myexperiment`).
  - **Comparison:** Benchmarks the execution time using `system.time()` for five methods:
    1.  `for` loop **without preallocation** (slowest)
    2.  `for` loop **with preallocation** on a vector
    3.  `for` loop **with preallocation** on a list
    4.  **Vectorized** using `sapply`
    5.  **Vectorized** using `lapply`
  - **Purpose:** Highlights the critical performance benefits of vectorization and preallocation in R.

## Getting Started

### Prerequisites

  - **Base R:** All scripts rely on standard R functionality (no external packages required).
  - **Data Structure:** The required data files (`KeyWestAnnualMeanTemperature.RData` and `trees.csv`) must be located in the `../data/` directory relative to the script location.

### Installation

1.  Clone or download the repository content.
2.  Navigate to the `week3/code` directory:
    ```bash
    cd CMEECourseWork/week3/code
    ```
3.  Ensure the necessary **data** and **results** directories exist one level up:
    ```bash
    # From inside the 'code' directory:
    mkdir ../data
    mkdir ../results
    # Place data files inside ../data
    ```

### Usage

Run any script using the `source()` command in an R console or via an IDE like RStudio.

```r
# Example for Correlation Analysis
source("1_temp_correlation.R") 

# Example for File I/O and data manipulation
source("3_tree_heights.R") 

# Example for Performance Benchmarking
source("4_performance_test.R") 
```

**Note**: Remember to set your working directory to the `code` folder or use full paths when sourcing.

### Help

  * **Data Path Errors:** If data loading fails, check that the `data` folder is correctly placed **outside** the `code` folder, as scripts use the relative path `../data/`.
  * **Slow Code:** For the performance script, note that the results consistently show that R is fastest when using the **vectorized** functions (`sapply`, `lapply`) or loops **with preallocation**. Avoid loops without preallocation for large datasets.

## Key Learning Outcomes

  - **Statistical Inference**: Implementing and interpreting Monte Carlo permutation tests.
  - **R Efficiency**: Benchmarking `for` loops against `sapply`/`lapply` and understanding the role of **preallocation**.
  - **Data Structures**: Working with R's vectors, data frames, and matrices using functions like `cor()` and `apply()`.
  - **Modular Programming**: Defining clear, reusable functions (`is.prime`, `calculate_height`).
  - **File I/O**: Reading and writing data using `load()`, `read.csv()`, and `write.csv()`.
